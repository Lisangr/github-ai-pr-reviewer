# Небезопасные практики в Dockerfile

Ищите в diff:
- запуск контейнера от root (отсутствие инструкции `USER`);
- использование тега `:latest` вместо зафиксированной версии образа;
- установку лишних утилит (curl, wget) в финальный stage без очистки кэша.

**Рекомендация:** создайте непривилегированного пользователя, зафиксируйте тег образа и используйте multi-stage сборки.
