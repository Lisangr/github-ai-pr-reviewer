# SQL-инъекции и небезопасные запросы к БД

Ищите в diff:
- конкатенацию строк, f-strings (`f"SELECT ... {var}"`) или `%`-форматирование при сборке SQL-запросов с внешним или пользовательским вводом;
- передачу сырых SQL-строк без параметризации / bind-параметров.

**Рекомендация:** используйте параметризованные запросы, prepared statements или безопасные методы ORM.
