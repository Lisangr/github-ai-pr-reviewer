# AI Security PR Reviewer

Автоматический ревьюер Pull Request на базе GitHub Actions и Google Gemini, который проверяет изменения кода по структурированной Markdown-базе правил безопасности и оставляет точечный комментарий в PR.

## Запусти у себя за 2 минуты

1. **Создайте форк проекта** в свой аккаунт или организацию на GitHub.
2. **Добавьте секрет `GEMINI_API_KEY`** в настройках репозитория (`Settings -> Secrets and variables -> Actions -> New repository secret`).
3. **Создайте новую ветку**, внесите изменения в любой файл (например, добавьте тестовый кусок кода с уязвимостью или захардкоженным токеном) и откройте **Pull Request**.
4. **Наблюдайте**, как бот автоматически придёт в комментарии к PR и разберёт ваш код с точки зрения безопасности.

## Структура проекта

- `.github/workflows/ci.yml` — валидация правил безопасности и проверка синтаксиса скриптов.
- `.github/workflows/ai-reviewer.yml` — запуск агента при открытии или обновлении PR.
- `security-rules/` — база правил безопасности в формате Markdown (`_index.md` генерируется автоматически).
- `scripts/build_index.py` — проверка frontmatter и сборка индекса правил.
- `scripts/pr_reviewer_agent.py` — получение diff через GitHub API, анализ через Gemini и публикация комментария.
- `CONTRIBUTING.md` — инструкция по добавлению новых правил.
